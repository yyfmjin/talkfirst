# TalkFirst「先聊」— 面向推广的项目分析

> 生成：2026-10-10（Kun 基于仓库代码、`readme` 规格书与线上实测撰写）
> 数据快照（2026-10-10 线上库）：5 个用户 / 2 条动态 / 1 个会话 / 12 条消息 / 1 个 connection
> 配套文档：`docs/COLD-START-PLAYBOOK.md`（阶段 0 冷启动执行清单）

## 1. 产品定位

**一句话**：面向全球用户的陌生人社交「缓冲层」——先通过兴趣/语言/国家找到人，站内聊天，**只有双方都同意后**才允许交换 Instagram / Telegram / WhatsApp / 微信 / Discord / X 等真实社交账号。

**Slogan**：先聊聊，再成为朋友。/ Talk First. Connect Later.

**核心闭环**：

```
注册 → 建社交名片（母语/在学语言/兴趣/目的）→ 系统推荐
  → 打招呼（Say Hello）→ 对方接受 → 聊天（内置翻译）
  → 双方有意 → 申请交换联系方式 → 对方同意 → 成为 Connection
```

**「不是什么」同样重要**（推广时避免被误解，来自规格书 §3.1）：
不是 Tinder 式约会 App、不是色情社交、不是随机视频聊天、不是聊天室、不是账号交易/涨粉平台、不是纯 AI 聊天。它是**交友 + 语言交换**，不是约会。

## 2. 差异化卖点（全部已实现、可直接验证）

| 卖点 | 依据 | 文案角度 |
|---|---|---|
| 联系方式双同意才交换 | `apps/api/src/exchange/`；官网安全条款 | 「对方不同意，你的联系方式到不了对方」——反骚扰、反泄露 |
| 内置翻译聊天 | `apps/api/src/translate/`（`MessageTranslation` 表） | 中英聊天无障碍，「练口语不怕打错字」 |
| 可解释的推荐 | `discover.service.ts`：语言30/兴趣25/目的20/国家15/活跃10，附「语言互补」「共同兴趣」等人话理由 | 「系统告诉你为什么推荐这个人」 |
| 每日限额、无滑卡 | Discover 每日配额（规格书 §31：不要让用户无限刷人） | 反 Tinder 叙事：不是无限刷人，是认真打招呼 |
| 安全是产品级承诺 | 举报/拉黑、动态先审后发、邮箱验证、IP 封禁、运营后台（举报队列 B4） | 陌生人社交最大的顾虑，这里是做出来的不是口号 |
| 送花（轻互动） | `UserFlower`：非现金、可撤回、一对一朵 | 「喜欢就送一朵花」，弱化功利感 |

官网（`apps/web/src/marketing/official-site.tsx`）已经把叙事立为三条：**语言交换 → 兴趣搭子 → 先聊再连**。推广围绕这三条展开即可，不用另造概念。

## 3. 目标用户（规格书 §5–§6 已定义）

第一阶段重点：**18–35 岁、想认识外国人 + 语言学习/游戏/音乐/旅行**。

| 原型 | 画像 | 需求 |
|---|---|---|
| A | 中国用户（兴趣：英语/游戏/旅行/音乐） | 「想找外国朋友练英语」 |
| B | 外国用户（如美国用户） | 「想找中国人聊天，练中文」 |
| C | 游戏玩家（Minecraft/Valorant/GTA 等） | 找游戏搭子 |
| D | 旅行爱好者（如准备去日本） | 想认识本地人 |

⚠️ **双边市场**：推广必须让「练中文的外国人」和「练英语的中国人」同时进场，否则哪边都会觉得没人可聊。这是冷启动最大的结构性风险。

## 4. 现状家底

**功能**（API 模块名即事实）：auth（邮箱 + Google OAuth）、onboarding（语言/兴趣/目的）、discover（推荐 + 打招呼）、chat（socket 实时 + 翻译）、moments（动态，先审后发）、videos、connections、exchange（双同意交换）、notifications、flowers（送花）、safety（举报/拉黑/IP 封禁）、social-sync（外部动态同步）、admin（用户/报表/审核后台）。

**平台**：官网（中/英双语）+ 网页版全功能 + **Android 内测 APK**（自托管直装，2026-10-10 发布修复白屏的新包）+ iOS 准备中。

**真实数据**（2026-10-10）：5 用户 / 2 动态 / 1 会话 / 1 connection —— 处于真正的冷启动。

**规格书自己的节奏**（§第九/十阶段）：**先找 20–50 人真实使用，再决定是否正式推广**。现在正处于这个验证期，不是大投广告的时候。

## 5. 推广节奏

| 阶段 | 目标 | 动作 |
|---|---|---|
| 0 · 种子（现在） | 20–50 个真实用户，验证闭环 | 运营账号 + 双边社群冷启动（见 COLD-START-PLAYBOOK.md） |
| 1 · 小范围放量 | 验证可传播性，补商店渠道 | Google Play 上架；把「为什么推荐你」「翻译聊天」「双同意交换」做成内容素材 |
| 2 · 正式推广 | 规模化 | 中文侧小红书/B站；英文侧 TikTok/IG Reels/Reddit；SEO（官网 meta 已就绪） |

## 6. 推广前建议补齐的三件事

1. **冷启动内容**：现在线上只有 2 条动态。运营先发 10–20 条真实、有梗的语言学习/文化动态（官网预览「小秋」那条是现成模板）。
2. **商店页资质**：Google Play 需要隐私政策链接（`/legal` 已有）、18+ 内容分级声明、应用截图（模拟器截图流程已跑通，可批量产出）。
3. **漏斗数据**：后台目前只有举报队列（B4），**没有增长漏斗看板**。阶段 0 先靠 SQL 周报（见 COLD-START-PLAYBOOK.md §4），放量前建议补一个最小漏斗页。

## 7. 变现方向（推广期不急，方向已定）

- 送花：已上线，纯好感表达、**不折现**（运营方明确要求）。
- 规格书规划：Premium $4.99/月（无限 Discover、高级筛选、翻译额度、查看谁喜欢你、Profile Boost、更多社交账号）+ Boost（30 分钟曝光）。
- 铁律（规格书 §91）：**不能付费买信任**——花钱 ≠ 更容易交换账号。这是产品长期口碑的底线，任何变现设计都不能碰。

## 8. 风险与合规注意

- **18+ 仅限**：官网已标注；商店上架必须配年龄分级。
- **内容审核是卖点也是成本**：动态先审后发 + 举报有人看，意味着运营期必须有人盯审核队列（建议响应 <4h）。
- **iOS 未上架**：iOS 用户先导到网页版（官网已有此引导）。
- **Cloudflare 拦截 AI 爬虫**（2026-10-10 实测）：GPTBot / ClaudeBot / PerplexityBot / Bytespider 访问官网返回 403（`Server: cloudflare`），普通浏览器正常。若要 SEO 收录或让 AI 工具推荐官网，需在 Cloudflare 后台关闭「Block AI Scrapers and Crawlers」。当日已同步解除源站 nginx 的 CF-only IP 白名单（备份 `talkfirst.conf.bak-20261010`），两者不是一回事。
- **冷启动期举报少，别松懈**：拉黑/举报能力是卖点，真实处置记录本身就是信任资产。
