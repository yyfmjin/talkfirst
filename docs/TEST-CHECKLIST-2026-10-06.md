## 0. 先给自己开个管理员（后台自测必需）

生产库现在**没有管理员账号**（也没有普通用户以外的数据：2 个用户、0 条动态）。在服务器上执行：

```bash
cd ~/talkfirst
node --env-file=.env scripts/make-admin.cjs 你的邮箱@example.com '你想设的密码'
```

- 输出 `ADMIN_OK {...}` 即成功；它会把该邮箱的用户建好或升级为管理员（`isAdmin=true`、邮箱已标记验证、状态 ACTIVE）。
- 不带邮箱跑会用默认 `admin@talkfirst.dev` / 密码 `123456` —— **测完记得改密码或删掉**。
- 然后到 `https://admin.talkfirst.ccwu.cc/login` 用这个邮箱密码登录。

成员端不需要验证码：生产 `ENFORCE_EMAIL_VERIFICATION=false`，注册完可直接用。

## 5. 明确「不是 bug」的清单（避免误报）

1. **未读数的显示上限**：底部导航现在显示真实总数，没做「5+」——那是个产品决定，尚未定。
2. **话题条数是「近期窗口」**：统计最近若干条可见动态，不是历史总数（语义在页面上写的是「近期话题」）。
3. **后台圆角仍是控制台密度**（8–14px），没有跟成员端的 18/24/28 —— 刻意的。
4. **成员端两处对比度不合格仍存在**：主按钮白字压 `brand-500` = 3.68、`warning-800` 徽标 = 3.90（都低于正文级 AA 要求的 4.5）。修法各一行，**等你点头**。
5. **E2E 的既有失败**：按 `docs/KNOWN-E2E-ISSUES.md` 保留，不作为门禁，别当回归信号。
6. **后台登录页那句域名**：现在读 `NEXT_PUBLIC_ADMIN_URL`（没配才回落到 `localhost:3001`），线上已配置为真实域名。
