## 1. 上线前准备（没做完之前不要拉人）

- [ ] **种子内容**：运营账号先发 10–20 条动态。空城（2 条动态）会劝退第一批用户，冷启动最难的一环。
- [ ] **空状态检查**：Discover / 消息 / 动态页在「没内容」时有没有引导文案，没有就先补。
- [ ] **审核值守**：动态是先审后发的（`Moment` + 管理后台审核队列）。冷启动期承诺处理时限：**< 4 小时**（最好有人值班），否则用户第一条动态卡在审核会直接流失。
- [ ] **注册链路自测**：邮箱验证（生产 `ENFORCE_EMAIL_VERIFICATION=true`）、Google 快捷登录、官网 `/download/android` 下载 APK 装机、网页版全流程各走一遍。
- [ ] **已知问题核对**：过一遍 `docs/KNOWN-E2E-ISSUES.md`、`docs/TEST-CHECKLIST-2026-10-06.md`，把用户一上来就会撞到的问题先修或先知道怎么回。
- [ ] **举报处理**：后台举报队列（Admin B4 已实现）。冷启动期举报也要 24 小时内响应——安全是产品的卖点，处理慢等于自砸招牌。

## 2. 运营账号怎么打

### 2.1 人设
- 一个中文母语、在学英语的账号（主攻中文侧），一个英语母语、在学中文的账号（主攻英文侧）。
- 用真人语气，不用官方语气。目标：新用户刷动态时觉得「这里有人在真的聊天」。

### 2.2 动态模板（每天 1–2 条，仿官网预览「小秋」的风格）
- 「今天在学『差不多』和『几乎』的区别，中文的同义词真的太微妙了。」（官网现成示例，直接用）
- 「有没有人懂，学英语三年了，点餐还是只会 this one and this one。」
- 「想找个人一起打 [游戏名]，我可以顺便教你中文/英语。」
- 「下个月去 [城市]，有没有本地人推荐不是游客去的地方？」
- 语言学习梗、文化差异趣事、游戏/旅行/音乐话题轮流发。

### 2.3 打招呼话术（用 Say Hello 的「自己写消息」）
产品内置四种破冰（both like gaming / learn about your country / practice languages / both like music），运营号手动打招呼时参考同一语气：
- 「看到你也在学英语，我们可以互相纠错。我中文母语。」
- 「你资料里写喜欢 [乐队/游戏]，我也喜欢，聊两句？」
- 「你准备去中国旅行吗？本地人（我）在线答疑。」

### 2.4 响应策略
- 新用户打招呼 **24 小时内回应**；冷启动期把「有回音」当第一 KPI。
- 用户资料不完整时，聊天里自然引导补全（推荐算法有资料完整度相关的匹配质量，资料越全推荐越准）。

## 3. 双边招募渠道清单

> 双边市场铁律：**两边同时开**。只拉一边，另一边进来没得聊，第一批全流失。

### 中文侧（练英语 / 想认识外国人的用户）
| 渠道 | 打法 | 注意 |
|---|---|---|
| 小红书 | 发「找语伴」日常帖，评论区/私信自然带出产品 | 不刷链接；一篇内容先跑起来再追加 |
| B 站 | 语言学习视频评论区、英语学习区动态 | 同上 |
| 英语学习 QQ/微信群、豆瓣小组 | 以「我建了个语言交换小社群」切入 | 先问群规，管理员同意再发 |

### 英文侧（学中文 / 想认识中国人的用户）
| 渠道 | 打法 | 注意 |
|---|---|---|
| Reddit r/language_exchange | 用周帖或符合版规的帖子「Chinese native looking for English partners」 | 多数版块禁止直接推广 App；先以「找语伴」身份入场，私聊时再提 |
| Reddit r/ChineseLanguage | 帮人解答中文问题，建立可信度 | 长期经营，不速成 |
| Discord 语言学习服务器 | 在 language-exchange 频道自然交流 | 看各服规则，别当 link spam |
| Facebook 语言交换群组 | 同上 | 同上 |

### 游戏侧（搭子）
- 对应游戏的官方/大 Discord 的 LFG（找队友）频道，以玩家身份切入，话题自然引到「边打游戏边练语言」。

### 通用守则
- **先给价值，再提产品**：帮人改作文、答疑、当语伴，然后才说「我们用 TalkFirst 继续聊吧」。
- 不要群发私信（很多平台直接封号），一对一、有上下文地聊。

## 4. 验证指标与 SQL（表名已按当前 schema 核实）

在服务器上执行（`psql -h 127.0.0.1 -U talkfirst -d talkfirst`）：

```sql
-- 打招呼漏斗
SELECT status, count(*) FROM "ConnectionRequest" GROUP BY status;

-- 交换联系方式漏斗
SELECT status, count(*) FROM "ExchangeRequest" GROUP BY status;

-- 聊天活性
SELECT count(*) FROM "Conversation";
SELECT count(*) FROM "Message";
SELECT count(DISTINCT "senderId") FROM "Message";

-- 7 日内活跃用户
SELECT count(*) FROM "User" WHERE "lastActiveAt" > now() - interval '7 days';
```

建议**每周跑一次并存进 `docs/` 下的一张进度表**（或后台加一个最小漏斗看板——现后台只有举报队列，没有增长漏斗，这是一个明确的小缺口）。

## 5. 冷启动常见陷阱

1. **空城**：内容比人先到。种子动态是第 0 步，不是第 3 步。
2. **单边市场**：只拉「想学英语的中国人」，进来发现没有外国人，全走光。
3. **垃圾号**：生产已开邮箱验证 + IP 封禁；运营看到可疑账号直接后台处理，别让种子用户先撞到骗子。
4. **运营号太官方**：发「欢迎加入 TalkFirst」没人看；发「有人一起打游戏吗」有人回。
5. **没数据**：每周漏斗 SQL 是判断「该继续还是该改」的唯一依据，别凭感觉。
